# Source Priority

Use this precedence when checking claims.

1. User-provided official source or current client document
2. Local `flight-school-knowledge/` reference with source links
3. Current client repo pages for client-specific claims
4. Extra information files supplied under `.agents/right-rudder-marketing/extra-information/`
5. Existing blog posts, only if no stronger source exists

## Official Source Preference

For FAA rules, training requirements, medical certificates, and checkrides, prefer official FAA or regulation sources in the source register.

## Client-Specific Source Preference

For pricing, fleet, staff, housing, airport environment, schedules, and program inclusions, prefer the client repo or client-supplied files.
