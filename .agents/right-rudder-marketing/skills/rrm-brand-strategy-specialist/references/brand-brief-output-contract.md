# Brand Guide Output Contract

Use this structure for `.agents/right-rudder-marketing/shared/outputs/brand-guide.md`.

The brand guide is a durable client-level artifact. Create it once, then update it only when source material changes the client's positioning, offers, pricing, proof, claims, audience, conversion paths, or voice.

Hard claims require source paths. Inferences must be labeled as `inference`.

For team bylines such as `[School Name] Team`, use warm school-staff voice. For named authors, include light persona guidance only when source material supports it. If the credited author has no usable bio, keep the byline but fall back to team voice.

If an existing guide is still current, do not rewrite it for style. Report "no update needed" and cite the source inventory reviewed.
