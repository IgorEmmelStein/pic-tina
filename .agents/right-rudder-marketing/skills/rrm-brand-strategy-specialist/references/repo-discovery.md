# Repo Discovery

Use this guide to find client-owned strategy material before asking questions.

## Search Targets

- Pages and routes: `src/pages`, `pages`, `app`, `content`, `src/content`
- Markdown or MDX content: blog posts, program pages, service pages, location pages, FAQs
- Data files: `src/data`, `data`, constants, JSON, CSV, YAML, CMS exports
- SEO folders: search console exports, keyword plans, existing snapshots
- Components with copy: hero sections, CTA sections, FAQ components, program cards
- Author and staff sources: existing blog frontmatter, author pages, team pages, about pages, instructor/staff bios, author images, and client notes that identify the credited writer
- Extra information: `.agents/right-rudder-marketing/extra-information/`

## Ignore

- `node_modules`, build output, cache folders, generated bundles, lockfiles, binary assets unless image paths are needed
- Confirmation pages unless conversion flow details matter
- Old or archived content unless no current source exists

## Output Expectations

Record the source path beside each important fact. Use repo paths, not vague labels like "website." When multiple files disagree, prefer current visible pages over old planning docs, then note the conflict.
