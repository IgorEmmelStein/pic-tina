# Blog Brief Output Contract

Deprecated for default workflow. Do not use this reference unless the user explicitly requests a tactical blog brief after being told that per-post title, metadata, angle, outline, links, CTA, and claims planning now belongs in `rrm-blog-copywriter`.

```markdown
## Claims For Aviation Fact-Check

## Outline Direction
- Opening answer:
- Required sections:
- Comparison/table opportunity:
- FAQ themes:
- CTA direction:

## Internal Links
- URL/path:
- Suggested anchor:
- Reason:

## Final Post Requirements To Plan For
- Program table links: every program name mention in a table should link to the individual program page when available.
- Section backlinks: every section should have at least one relevant internal backlink.
- Financing: the final post should mention financing at least once with sourced or qualified wording.
- Bold emphasis: note terms or decision points worth bolding when relevant.
- Hero image: choose or request a `heroImage` that has not already been used by another blog post.

```

A blog brief should make the eventual post easier to write and harder to make generic.
